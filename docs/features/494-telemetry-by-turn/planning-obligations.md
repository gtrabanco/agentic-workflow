## Notes

- O16's `rg` deliberately excludes the suites: a test may import a producer to
  prove a shape, and `scripts/telemetry-coverage.test.mjs` imports only the
  published vocabulary. The rule the row protects is "no producer outside the
  package", not "no import".
- O19's rows are the ones whose assertion text must not move: if a diff touches
  an existing assertion in those three suites, this unit changed behaviour
  nobody asked it to change.
