## Decision log

| ID | Decision | Rationale |

| D11 | P7's vector kNN runs as JS cosine over D4's float32-LE BLOBs, not a `sqlite-vec` vec0 table. D9's probe (G1) proved loadability, but D4 already stores the vectors as pinned-model BLOBs in `chunks`; a vec0 table would duplicate every vector into a second store (fixed dim at creation, per-provider rebuilds) — exactly the "complexity that is not needed" D8's criteria exclude. D9's probe stays on record as the measured upgrade path; the vectors are backend-agnostic, and AC15's judge gate gated the ship either way. Re-open only if a live corpus outgrows the JS cosine scan. | D4 + D8 read together; D9's condition was loadability, not storage. |
| D12 | F36+F37 fold: `store.path` is constrained to the repository's `.agentic-workflow/` directory — the only surface the committed ignore rules cover — with containment anchored at `realpath(root)` and the candidate resolved through the realpath of its deepest existing ancestor (the leaf may not exist yet), so symlinked intermediates and a symlinked `.agentic-workflow` itself fail closed (F25/F29/F36 line). F37's AC7 porcelain form is asserted in the AC24 target-project block with a configured nested path. | F37's route names the constraint option; the nested `.agentic-workflow/.gitignore` (F38) covers exactly this dir, so constraint + fixed negation make AC7's git-clean assertion hold for every accepted config. |
| D13 | F50 fold: containment is a property of the RESOLVED store path, not of the config's shape — `loadConfig` runs `containStorePath` on every branch (explicit `store.path`, config without a `store` key, absent config), always on exactly the path `storePath()` will use (the default when `store.path` is falsy). A symlinked `.agentic-workflow` with no `index.json` therefore fails closed instead of writing (and `--rebuild`'s `rmSync` destroying) outside the repository. | F50's reproducer: the absent-config branch returned the defaults uncontained — the F36 guard only ran when the config carried an explicit `store.path`. Containment must hold for the path actually used, whatever config shape produced it. |
