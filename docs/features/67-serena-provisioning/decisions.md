## Assumptions

Cheap-to-change defaults taken by the orient stage (stage 2), correctable by the
owner at any time — never silent.

- **A1 · 2026-10-21 — the install command is the verified one.** `uv tool
  install -p 3.13 serena-agent && serena init` (INV-005, INV-006), not the
  issue's "uvx preferred" wording: pi-serena discovers Serena only through
  `uv tool dir`'s `serena-agent` python or `SERENA_PYTHON`, so an ephemeral
  `uvx` environment would never be found. Correct this if the owner prefers
  the ephemeral form.
- **A2 · 2026-10-21 — MCP registration targets the detected platform only**,
  offered inside the same consented Serena question (INV-019). Widening to
  more platforms later is additive and consent-gated.
- **A3 · 2026-10-21 — the pi path needs no MCP registration.** pi-serena is a
  Pi extension that "avoids configuring Pi as an MCP client" (INV-003); only
  the non-pi path registers an MCP server.
